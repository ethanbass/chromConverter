# Shimadzu GC-FID alkane ladder

An ASCII export from 'Shimadzu LabSolutions' of a GC-FID run (GC-2014)
of an n-alkane ladder with nonadecane (C19) added, sampled by
solid-phase microextraction, holding its peak table of 83 peaks and the
chromatogram, recorded every 40 ms for 44 minutes. Find it with
`system.file("extdata", "alkane_ladder.txt", package = "chromConverter")`.

## Source

Andrew W. Legan (<https://orcid.org/0000-0001-7049-9837>). The binary
file of the same run is `FS19_214.gcd` in 'chromConverterExtraTests'.
